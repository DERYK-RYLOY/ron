From bitmap to vector

Ron began as a hand-cut 61×61 bitmap alphabet — forty-eight glyphs of chamfered, negative-space geometry. Every RON file ships the same skeleton, traced to Bézier outlines and re-rendered five ways. No blur. No hinting compromises. Just weight.
// use it from css in 6 lines
@font-face {
  font-family: 'RON Black';
  src: url('RON-Black.woff2') format('woff2');
}
.hero { font-family: 'RON Black'; }

Lowercase maps to caps by design — Ron is an all-caps display face that refuses to whisper.
